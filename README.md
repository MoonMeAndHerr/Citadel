# 🏛️ SCIENCESS Citadel

> **The Centralized Administrative Portal & Operational Command Hub**  
> *Sciences' Students' Society (SCIENCESS), International Islamic University Malaysia (IIUM)*

---

## 📌 Overview

**SCIENCESS Citadel** serves as the definitive, unified administrative hub for the Sciences' Students' Society (SCIENCESS). Built to enforce operational efficiency, transparency, and structure across the Kulliyyah of Science, Citadel centralizes proposal approvals, post-event reporting, document submissions, and parcel intake management into a single secure platform.

---

## 🚀 Key Features

* **📜 Proposal & Report Submission Engine**  
  Automated submission workflows for program proposals, budget requests, and post-event administrative reports with live tracking status.
* **📦 Parcel Management System**  
  Centralized logging, notification, and collection verification system for society inventory, club packages, and student deliveries.
* **📑 Document Repository**  
  Standardized access to official templates, guidelines, constitutions, and administrative forms.
* **🛡️ Role-Based Access Control (RBAC)**  
  Tailored access permissions for executive committees, department heads, and general student members.

## 🛠️ Tech Stack

* **Frontend:** React / Next.js / Tailwind CSS
* **Backend:** Laravel / Node.js / Python
* **Database:** PostgreSQL / MySQL
* **Deployment:** Docker / Vercel / Self-Hosted Server

## ⚙️ Getting Started

### Prerequisites

Ensure you have the following installed on your local environment:
* Node.js (>= 18.x) / PHP (>= 8.2)
* Git
* Database Engine (PostgreSQL / MySQL)

### Installation Command

Run the following command sequence in your terminal to set up the project:

git clone [https://github.com/your-org/sciencess-citadel.git](https://github.com/your-org/sciencess-citadel.git) && cd sciencess-citadel && npm install && cp .env.example .env && npm run migrate && npm run dev
